How to Import Into GoodNotes

  1. Purchase and download your planner PDF from The Planner Hup.
  2. Open GoodNotes and create a new document, or import directly using "Import PDF."
  3. Select your downloaded planner file from your Files app.
  4. Start planning — tap any tab to navigate instantly.
