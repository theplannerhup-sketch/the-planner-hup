How to Print at Home

  1. Download your PDF after purchase.
  2. Open the file and select Print, choosing A4 or A5 paper size.
  3. Set scaling to "Actual Size" (not "Fit to Page") for correct margins.
  4. Print, punch holes if binding, and start planning!
